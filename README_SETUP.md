# تعليمات تشغيل مشروع MUQ

## طريقة 1: التشغيل التلقائي (موصى به)

### الخطوة 1: تهيئة قاعدة البيانات
افتح موجهة الأوامر (Command Prompt) كمسؤول، ثم شغل:
```
F:\MUQ\backend\setup_db.bat
```
هذا سيقوم بتهيئة قاعدة البيانات وإنشاء مستخدم admin:
- Username: `admin`
- Password: `admin123`

### الخطوة 2: تشغيل الخوادم
افتح موجهة الأوامر و شغل:
```
F:\MUQ\start-servers.bat
```
سيقوم بتشغيل:
- Django Backend على: http://localhost:8000
- Frontend على: http://127.0.0.1:58272

### الخطوة 3: الوصول إلى المشروع
افتح المتصفح على: http://127.0.0.1:58272
- انقر على "تسجيل الدخول"
- استخدم: admin / admin123

---

## طريقة 2: التشغيل اليدوي

### تشغيل Django Backend:
افتح موجهة الأوامر واتبع خطأ:
```
cd F:\MUQ\backend
python manage.py runserver
```

### تشغيل Frontend (في نافذة أخرى):
افتح موجهة أوامر أخرى واتبع:
```
cd F:\MUQ\frontend
python -m http.server 58272
```
